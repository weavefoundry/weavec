Every major design decision has a written record: the problem, the proposed semantics, the tradeoffs, and the evidence required. These RFCs are the authoritative design references for WeaveC.

**Accepted** records specify the design. **Implemented** records have completed their defined implementation and test criteria. **Superseded** records are kept as history; the record that replaced them says what changed. [RFC 0035](/rfcs/0035-guard-by-default/) defines the guards and [RFC 0036](/rfcs/0036-deterministic-heap-reuse/) the current guarantee. Earlier records that specify the ownership analysis RFC 0036 deleted are kept as history. A status is not a guarantee about arbitrary C programs; consult each RFC's scope and validation.
